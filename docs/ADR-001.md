# ADR-001 — HomeCore hybrid multi-tenant foundation

Status: Accepted for MVP scaffolding.

- Cloud: Django + DRF + PostgreSQL, shared schema with tenant scoping.
- Local: separate Django and Home Assistant, independent of subscription status.
- Agent: outbound authenticated TLS connection; later sprint.
- Commercial: perpetual local entitlement and optional per-home remote subscription.
- Multi-tenancy: tenant memberships and home memberships; never trust tenant IDs supplied by clients.
- Isolation: enforce service-level authorization and later PostgreSQL RLS; current scaffold has **no business API**.
- Provisioning: one installation per home for MVP, extensible later.
- UUIDs for publicly referenced entities.
- Payments, remote commands, pairing, signed licenses, mobile and HA integration are out of scope for Sprint 001.

Security gates before production: hardened settings, credential rotation, audit trail, auth provider, permissions, cross-tenant endpoint tests, CI security scanning and backups.
